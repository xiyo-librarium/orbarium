# Orbarium

**Choose a land. Close the loop.**

世界のどこかの土地を選び、雨・太陽・土・生き物との関係を一から作っていく循環シミュレーション。
公開先: https://orbarium.x1y0.net

## いまの中身（試作）
- 序章：東京の30m²の部屋（見るだけ）。関わる相手は「お金」だけ
- 地球儀で東京からメデジンへ
- メデジン：左に1mメッシュの敷地図、右にダッシュボード（関係の網・家計簿・予定・天気・ノート）
- 1ターン＝3か月。中は1日ずつ計算（雨水・排水・土の水・養分・有機物・電気・お金）
- 困りごと（断水・停電・乾き・土の流出・害虫・地盤）から技術を1つずつ学ぶ。天気の記録から先読みもできる
- 図鑑：地球儀で世界の仕組み（カナート、アンデネス、チナンパ…）を学ぶ
- 章の目標：豊かな関係を12にする
- 旧試作は `/proto/`

## 構成
- `public/` 配信するファイル（ビルドなし、ES modules）
  - `js/engine.js` 計算エンジン（純関数、nodeでも動く）
  - `js/content.js` 文章・図鑑
  - `js/globe.js` 線で描く地球儀（canvas）
  - `js/app.js` 画面
- `tools/bots.mjs` 自動テストプレイ（作戦ごとのボットで点検）: `node tools/bots.mjs 10 20`
- `tools/ui_test.py` ブラウザで一周遊ぶテスト（Playwright）

## 仮の値
天気は平年値に年ごとのゆらぎとエルニーニョ／ラニーニャを確率で重ねたもの。停電・断水の回数、地形（友人の土地）は仮。
