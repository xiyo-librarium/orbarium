# Orbarium

**Choose a land. Close the loop.**

世界のどこかの土地を選び、雨・太陽・土・生き物との関係を一から作っていく循環シミュレーション。
公開先: https://orbarium.x1y0.net

- 本番（/）は作り直した版（画面の中身は public/game/、計算の中心は public/js/。下の「作り直し」の節）。前の置き場所 /next/ への古いリンクは / へ転送する（public/_redirects）
- 前の版は記念に /classic/ に残す（画面からのリンクはなく、検索にも出さない）。前の版だけの物は public/classic/ にまとめてある（index.html・classic.css・js/app.js・js/globe.js）。計算の中心（public/js/）と、日差しの向きの計算（public/js/iso.js）は本番と共有。保存のキーは別。下の「前の版の中身」はそちらの説明

## 前の版の中身（/classic/）
- 地形は1mのキューブ（等高線の1mごと＝1段）
- 光は本物の太陽の向き：その土地の緯度・季節・時刻から日差しの向きと高さを出し、面の向き（東西南北）と斜面の傾きで明るさが変わり、段差や家の影が落ちる。3Dの［☀］で時刻（8〜16時）を切り替えられる。地図も同じ日差しで斜面に陰影がつく
- 質感はつや消し：色を少しくすませ、日差しはあたたかく、日かげは空の光でやわらかく。窓・腰壁・扉・布団の模様も、面の光を乗算で重ねて、模様だけが明るく浮かないようにする。窓は昼の外から見た暗いガラスに木の桟（つやの線は描かない）。葉は光を通すので日かげの側も沈ませない
- 影と光の計算（3D）
  - 地面の影：地面の上の点ごとに日差しの逆向きへ高さの地図をたどり（1マスを4×4、影の縁は10×10）、小さく描いて引きのばしてやわらかくする。1mの段は本当はなだらかな斜面なので、段の縁の影は落とさない（家・木・物と大きな丘の影だけ）。地面の上面だけにかかるよう型で切り抜いて掛け算で重ねる
  - 日差しの色は太陽の高さで変わる（低い朝夕は金色）。空の光と日差しの割合は 0.58：0.52、日かげの壁には地面からの暖かい照り返し
  - 軒の影：雨の流れ落ちる側の外壁に、軒の出×日の高さ÷壁に向かう日差しの強さ の高さの影の帯
  - 素焼きの瓦は1枚ずつ：山と谷の列、山の瓦は日の側が明るく、谷には山の影。40cmごとの段の縁が明るく、その下に影（日が低いほど長い）。山と谷の段はずれる。焼き色と苔のむら
- 地図を押すと、その場所を拡大した3Dの「設計図」。上の棚［家・畑と植栽・水・小屋と設備・土地と木］から道具を選び、地面を押す（1つ）・なぞる（四角・並べる）。家も畑も水まわりも、設計図の上ではお金はかからず、下の見積もり（いま → この設計：家の熱、タンクに入る屋根、タンク、畑、太陽光、ため池、新しく出る注意）を見てから［この設計で頼む］。足すものは青、外すものは赤で見える。畑・水・小屋と設備・土地の道具は、木や家に隠れていても指した所の地面のマスをねらう（段々の斜面でずれない）。ねらっているマスは一番上に白い枠で出し、なぞった四角の下見もその地面の高さに出す（前は家の床の高さに浮いていた）。元に戻す・やめる・閉じる前の確認つき。覚えていない作り方は出さず、「あと○つ」とだけ出す
- 家：最初は前の持ち主が建てた小さな板壁の家（4×3m、高さ3m）。トイレ・シャワー・ベッド・テーブルと椅子つき。家を選ぶと設計図モード：
  - 地面をなぞって床を広げる・減らす、外壁を押して窓・扉を付ける、壁・屋根・床の素材を家全体で着せ替える（カードに断熱と熱をためるの目盛り・値段）、家具を動かす・トイレとシャワーの種類を替える（コンポストトイレ・節水シャワー）
  - 見え方は「設計（手前の壁を下げる）」「壁を下げる」「真上から（北が上、等高線つき）」「できあがり」
  - 設計の上ではお金はかからず、右に「いま → この設計」の見積もり（費用の内訳、暖房、暑すぎる日、屋根の裏の水滴、雨を集める屋根）。［この設計で建てる］で払って建つ。［元に戻す］［やめる］つき
- 制約：家の床は同じ段（1段ちがいは掘るか盛ってそろえる）、タンクは家や小屋の屋根の隣で屋根より低く、水は1段以上高い所からなら重力・低ければポンプ
- 木：林・やぶ（WorldCover）の木と茂み、植えた果樹・生け垣は、［土地・木］の［木を切る］で切らないとどかせない（木のマスには畑も家も作れず、掘れない）。切った木はとっておき（w.wood、m³）、まず堆肥のチップに（木1m³→チップ2.5m³。落ち葉で足りない炭素を補い、おがくずを買わずにすむ。チッパーの手間賃は近所へ）、残りは家に「薪のかまど」（素材→そのほか、6万円）があれば料理と暖房の薪に（木1m³で料理なら約400kWh、暖房なら約1100kWh分の電気が減る。エネルギーの輪では薪も自分の土地のエネルギー）。それでも余った木は薪として近所に売る（かまどがあれば1年分を残し、3か月に1m³まで、1m³0.6万円）。大きな木を建材・家具にするのは、要素が増えすぎるので今は入れない
- 水を見る（設計図の［水］）：斜面の青い筋（地形をならした高さで、段々の平らな所でも流れる向きを決め、水が集まる所だけ太く）、タンクの水位（手前を透かす。いまの季節の水。雨の入らないタンクは空）、畑の土の湿り気（濃い／白っぽくひび）。木や家に隠れた所は描かない（当たり判定の絵で確かめる）。［雨の日を見る］で大雨の1日（メデジン35mm、タオス18mm）を9秒で：雨粒、樋から落ちる水、水位が上がりあふれる、筋が流れる。終わると、タンクに入った量・あふれた量・軒から落ちた量・流れ去った量・土の湿り気の目安を出す
- 土地の工法は、1つの土地に壁・屋根・床を1つずつ（メデジン：バハレケ・素焼きの瓦・素焼きタイルの床、タオス：アドベ・土の平屋根・土の床）。赤れんが・版築・わらは古いセーブのために残すが選べない。バハレケは壁の上の仕上げを選べる：土のまま（カブヤの繊維と石灰を混ぜた土の色むら）／しっくい。どちらも下の腰壁（ソカロ、浮き彫りの枠とひし形）と窓枠・扉は6色から選べる
- 土地の工法（素材タブ、「この土地の工法」の札）：その土地でだけ選べ、地元の大工さんの仕事なので値段どおりでお金は地域に回る（よその土地なら1.6倍で材料は遠くから。world.regional）。壁には「地震に強い」「雨に強い」の目盛り
  - メデジン：竹と土壁（バハレケ。白いしっくいに、色を選べる腰壁（ソカロ）の浮き彫りと、同じ色の窓枠・扉。地震に強く雨に弱い）、赤れんが（ラドリージョ。目地と鉄筋コンクリートの梁）、版築（タピア・ピサダ。突き固めた層と型枠の穴。重く熱をためるが地震と雨に弱い）、素焼きの瓦（テハ。山と谷の瓦と重なりの段、切妻なら棟瓦。傾けた屋根だけ。重いので地震に少し弱く）
  - タオス：日干しれんが（アドベ。泥塗りのむらと梁の木口、青緑の窓枠と扉。毎年の泥の塗り直しの手入れ代）、わらのブロック、土の平屋根（ビガとラティージャ。パラペットで囲み、各辺に1本の木の樋カナレ。雨樋は要らず屋根全部の雨がタンクへ。軒は出さない）
  - 地震（メデジン、3か月に2.5%）：壁の強さ（と瓦の重さ）で修理代が変わる。バハレケはほぼ無傷
  - 雨：雨に弱い壁は、軒の出が浅いと雨の多い季節に傷む（深い軒でほぼ防げる）
  - 乾いた土地（一年の雨が少ない）は、草地をセージ色の乾いた草と砂の色に寄せ、草も低く少なく
- 窓：同じ壁で窓がとなり合うと、あいだの枠をなくして1本の連窓に（窓台も続ける）
- 石垣：［土地・木］で段差のふち（上の段のはし）をなぞると、そのマスの段差の面を石で積む（1m²＝長さ1m×段差1m、0.25万円）。ふちまで耕した段差は大雨で水と土が流れ落ちる（流出が増える）が、石垣はすき間から水を少しずつ逃がして土を留める。石が昼の熱をためて、石垣に接する畑は夜も約2℃暖かい（寒い日も育ち、18℃未満の日は6%よく育つ）。すき間のトカゲ・クモ・甲虫が畑の虫を食べる（虫害の確率が下がり、関係の網のトカゲと虫が増える）。土砂崩れも防ぐ。ふちを畑にせず草の帯を残すのも手（そのぶん畑は狭い）
- 堆肥小屋（［小屋・設備］）：柱とトタン屋根の半屋外の小屋に、すのこで囲った区画（1区画1m³）。なぞった四角の1マスが1区画。となりも区画なら、屋根と仕切りをつないで1棟に（柱は外の角と2mごと）。
  台所の生ごみ・コンポストトイレのし尿・ニワトリのふん・畑の残さを、落ち葉や刈り草（区画の林・果樹・生け垣から。足りなければ製材所のおがくずを買う）と混ぜて寝かせる。
  1区画がさばける量は年1.6m³ほど（し尿は1年寝かせる。寒い土地ほど少ない）。入る量に対して区画が足りないと、さばけない分の養分は畑に戻らず、し尿は汲み取りを頼む（お金は遠くへ）。見積もりに「堆肥でさばける ○%」
- tools/rules_test.mjs：木と堆肥の決まりごとの点検
- 雨樋：家（素材→そのほか）、小屋・堆肥小屋（［水］の［雨樋］で屋根を押す）に、軒どい（1m 0.35万円）＋たてどい（0.8万円）。雨樋がないと、軒から1m以内のタンク1つにつき屋根1.5m²ぶんの雨しか入らない。雨樋があれば屋根全部の雨が入り、そのタンクにつないだタンク（となりの同じ高さか低い所、真下）にも回る（水は下へしか流れない）。堆肥小屋の屋根（1区画1.1m²）も雨を集める
- 動かす：タンク・ポンプ・太陽光・ニワトリ小屋・沈殿槽は［動かす］で持ち上げて置き直せる（使い回せるので、動かすのはただ。上に積むことも）
- 薪のかまど：家具として床に置かれ（家具タブで動かせる）、煙突が屋根から出る。木がとってあれば煙が出る。天板のやかんと鍋からは湯気が立つ
- 屋根の形と軒の出（素材タブ）：ほぼ平ら／片流れ（北・東・南・西のどれへ下げるか）／切妻（北と南へ・東と西へ）。傾きは ゆるい9°／ふつう17°／急27°／とても急39°（雪の土地向け。雪の重さや落ち方は、雪の土地を入れるときに）。平ら以外にすると屋根を張り替え（1m²あたり屋根材×傾きの分＋0.4万円）、壁の上に三角・台形の妻壁（壁材の値段）。雨は下がる側の軒にだけ落ちるので、雨樋はその軒だけ（片流れは安い）、タンクもその軒のそばでないと入らない。軒の出は 0.16〜1.5m（1m²あたり1万円）で、深いほど屋根が広がり（雨樋つきなら雨を多く集める。外周×軒の出＋出隅の角）、夏の日差しと壁の雨を防ぐ。軒は角まで張り出す（旧データの庇あり＝0.5m）
- ［めぐり］：水・食べもの（養分）・エネルギー・お金を、どれも同じ形「入口 → 備蓄 → 出口」で見る（直近1年を1年あたりに直す）
  - 入口の色：土地（緑）／人とのやりとり（紫。薄いほど貸し借りがゆるく、濃いほどその場できっちり清算）／共有の網（青。水道・電力網・下水）
  - 備蓄：タンクと池、食料庫、蓄電池と薪、所持金が「何日分（お金は何か月分）」あるか
  - 出口の色：戻す（青緑。土へ戻す・使い回す）／渡す（分けた・売った）／漏れる（灰。流れ去る・下水とごみ・熱）。エネルギーは使えば熱になり、戻せない
  - お金は人とのやりとりを、その場で清算する道具として、近所か遠くかで分ける
  - 最初の季節の前は、くらべるために東京のころの流れを出す
  - 季節の報告にも、流れごとの細い帯（入口 → 出口）と「土地から／戻す」の割合を出す
- メールは受信トレイの窓（差出人・宛先・日付・件名・本文・添付のノート）で届く
- 作るものは近所の職人さんに頼む（材料費＋人件費。人件費は近所に回る）
- はじめから → 地球儀は東京の上で止まり、友人トミー（設計士、いまはヘルシンキに出張中）のメールが届く。［メデジンに行く］でメデジンへ飛ぶ（実データはメールを読んでいるあいだに裏で取る）。着いたら「この土地の気候」（年の平均気温・朝の最低〜昼の最高・一年の雨・雨の日を東京と並べ、月ごとの気温の帯と雨の棒、気候の特色と暮らしへの効き方）。メニューからいつでも見られる。特色の文章は content.js の CLIMATE、数字は実データから計算
- 実データ：遊んでいるブラウザが、移動中に取ってくる（public/js/realsite.js）
  - 標高：AWS Terrain Tiles（Mapzen、Terrarium PNG、ズーム15）を50m四方・1m間隔に補間して、1mの段にする。コロンビアは元が約30m間隔なので、傾きと向きは本物、細かい起伏はなめらか
  - 気候：Open-Meteo の過去の気象（ERA5、2014〜2023年の日ごとの値、区画の標高で補正）から月ごとの平年値（気温・雨・雨の日・日照）を作る
  - 植生：ESA WorldCover 2021（10m、CC BY 4.0）。Microsoft Planetary Computer のタイル（値のまま）、だめなら Terrascope の WMS（色から読む）。1mごとに少しゆらして読み、林は3m四方に1本の木（広葉樹・マツ・ユーカリ）、やぶは茂み、草地・畑のあと・土・湿地は地面の色と小物で描く。木の下は日かげ。何かを建てるとそのマスの木は切りひらかれる
  - 区画の選び方：決まった地点のまわり（半径約250m）で、WorldCover の「建物・舗装」と OpenStreetMap の建物（＋まわり12m）・車の道・水にかからず、急すぎない50m四方を探し、いちばん近い所にする（人の家の上に区画を置かない）。メニューの「この土地のデータの出典」に、選んだ場所と出典を出す
  - 使えない画像：Google の航空写真・Esri World Imagery は商用のゲームでは使えない条件なので使わない
  - 同じ場所はブラウザに覚えておく。取れなかったときだけ作り物の地形と仮の気候で始め、画面に「仮の地形」と出す
  - 場所を自分で選ぶのは、有料の「どこでもモード」で（無料の土地は場所が決まっている）
  - テストでは tools/mock_real.py が通信を横取りして、決まった形の標高タイル・気象・被覆（中心に集落、北西に林）・OSM の家と道を返す。区画が集落と道と家をよけたかを確かめる。見た目の確認は tools/shot_veg.py
- メデジン：左に1mメッシュの敷地図、右にダッシュボード（関係の網・家計簿・予定・天気・ノート）
- 1ターン＝3か月。中は1日ずつ計算（雨水・排水・土の水・養分・有機物・電気・お金）
- 困りごと（断水・停電・乾き・土の流出・害虫・地盤）から技術を1つずつ学ぶ。天気の記録から先読みもできる
- 図鑑：地球儀で世界の仕組み（カナート、アンデネス、チナンパ…）を学ぶ
- 章の目標：流れを回す担い手を10にする。達成すると、迎えてくれた人からメール（その季節の水・食べもの・地域で回るお金の割合と、作った堆肥の仕組みに驚く）。置いたものは持っていけない（技術・所持金・週の過ごし方は持っていく）
- 次の土地は、届いた招待から選ぶ（engine の ROUTE）。招待は、今いる土地でめぐりができてから、条件がそろった土地から届く。どれに行っても、もう少し残ってもいい
  - メデジンを終える → ウブド（ワヤン）とアレンテージョ（イネス）の2通。トミーのメールが二人を紹介する
  - ウブドかアレンテージョを終える → 八ヶ岳の麓（ハル）
  - 節水の器具と温室を覚える → タオス（レイ）。節水は水を運んでもらう土地（アレンテージョ・タオス）、温室は霜の降りる土地（八ヶ岳の麓・タオス）で覚える。地震の土砂崩れでも覚える「深い基礎」や、結露でも覚える「断熱」は鍵にしない
  - 招待は季節の報告に届き、ノートの［メール］にとっておける（［〜へ行く（土地代）］はいつでも押せる）。行っていない招待があると、場所の札のとなりに［次の土地へ］（スマホでは封筒と数）。まだ届いていない招待は、鍵と条件だけ出す
  - 似た難しさの土地をあとから足すときは、ROUTE に同じ after で並べる（例：八ヶ岳の麓と同じ段にもう1つ）
- 節水の器具は、水を運んでもらう土地（アレンテージョ・タオス）で覚える（運んでもらう水が高い・タンクが空になったとき、近所の人から。天気の記録から先読みもできる）。メデジンとウブドは雨が多いので覚えない
- マルチ・温室の覆いは、なぞった四角の中の畑にまとめてかける（最初に押した畑がもう覆ってあれば外す）。なぞって並べる道具（果樹・生け垣・掘る・盛る・木を切る・石垣）は、速くなぞってもマスを飛ばさない
- 旧試作は `/proto/`

## 作り直し（本番 /、中身は public/game/）

計画は「Orbarium 作り直し計画」の文書。

- 描画は three.js（public/vendor に同梱。r187 を最小化、MIT ライセンス）。組み立ての仕組みは使わず、importmap で読む
- public/game/look.js：つや消しの材料。色のむらと凹凸を世界の位置から決めるので、壁や屋根がいくつに分かれていても継ぎ目が出ない。土地ごとの色の組み合わせ、太陽の高さで変わる日差しの色
- public/game/land.js：本物の標高（1m の段）を、描くときだけマスの中心をつなぐなだらかな斜面にする。植生の色、草の株
- 畑は段々畑：畑のマスはその段の高さで平らにし（地面もそこだけ平らに削る）、上り側は切り土の斜面、下り側は土の壁（石垣があれば石）。同じ高さの畑は1つの段にまとまり、段の上に板で囲った盛り土の畝。計算の「段差（risers）」と同じ形
- public/game/trees.js：木は一本ずつ形が違う。幹と枝の骨組みを先に作り、枝先に葉の房を付ける。形と色は場所から決まる乱数で選ぶ（同じ木はいつも同じ形）
  - 広葉樹：丸い・横に広い・縦に長い・二股の 4 つの形。少し傾き、房の数・大きさ・向きもばらばら。上の房ほど明るい
  - マツ：段の数・太さ・ずれが木ごとに違う。段の縁は波打ち、裾が少し垂れる
  - ユーカリ：白っぽい細い幹が高く伸び、灰みどりの房がまばらに付く
  - 茂み：1〜3 個のかたまりが寄り合う
  - 家に枝がかかる木は、建てるときに切ったことにする
- public/game/house.js：家のデータ（床・屋根の形・傾き・軒の出・開口・工法）から形を生やす。辺ごとの壁、丸い角、腰壁と白い線、窓（枠・ガラス・桟・窓台）、扉、石を積んだ基礎、屋根の下地と鼻隠し、素焼きの瓦を1枚ずつ（山と谷、段の重なり、焼き色と苔のむら、棟の瓦）
- public/game/view.js：太陽1つ（緯度・月・時刻から本物の向き）とやわらかい影、空と地面の光、すき間の暗がり（GTAO）、霧。カメラは自由に回せるが真上と真横は見せない。動かしたときだけ描き直す
- 時刻の光（look.js の skyLight）：太陽の高さごとに、日差しの色と強さ・空の光（影の色）・空と霞の色を決め、間をなめらかにつなぐ。低いほど日差しは金色〜あかね色、影は青く、地平は暖かい霞。朝は淡く（黄〜桃）、夕方は濃く（橙〜あかね）。朝夕は少し明るめに写す。環境の光は時刻を変えるたびに焼き直す（1コマに1回まで）
- 木漏れ日：葉の影は、影を作るときだけ丸い穴と小さな抜けをあける（customDepthMaterial）。穴の模様は日の向きから見た葉のかたまりごとに固定するので、時刻を動かしても踊らない。木の外側ほど日だまりが多く、真ん中は濃い
- ピント：回す中心（見ている所）に合わせ、奥ほどぼかす（BokehPass）。ぼけの強さは距離で割って、寄っても引いても同じ見え方に
- 質感の分け方：建物は凹凸のあるつや消し、植物と地面はさらっと（凹凸なし・照り返しは弱く・葉は少し光を通す）。建物が主役に見えるように。地球は紙粘土のようなつや消しのまま
- public/game/globe.js：机の上の地球儀。海も陸もつや消し（海は塗った紙、陸はその少し上に重ねた紙粘土。海岸線の型で切り抜く）。宇宙の太陽ではなく部屋の光（見ている側の左上から）。影は落とさず、暗い背景に浮かんで見せる
  - 陸の起伏は実際の標高：AWS Terrain Tiles（土地の画面と同じデータ）の z=3 の64枚から、傾きを法線の画像にする（寄っても薄まらない）。高さはほぼそのままの割合で（低い平地を持ち上げると海岸が崖になる）、少しならす。紙のむらと色づきは地球儀に貼りつけてあり、回しても流れない
  - 読み込み：山脈の標高は海岸線と並べて読み始め、そろってから黒い覆いが明ける（8秒で届かなければ先に出し、あとから足す）
  - はじめは暗く沈んだ色。めぐりができた土地が増えるほど全体が明るくなる（&glow=0〜1 で試せる）。めぐりができた（章を終えた）土地のまわりだけ本当の色になる。住んでいるだけでは色づかない（住んだ年が長いほど広く：9°＋1年3°、28°まで。ふちは少しにじむ）
  - 横長の画面では地球を大きく左へ寄せ、題名のカードは右
  - 寄り方：手で回す地球儀。地球儀そのものが軸のまわりに勢いよく回り出し、少し行き過ぎて戻る（減衰ばね）。行き先の真上に来たらピンが刺さり、真上から寄り始めると同時に暗転を始め、黒になりきったら土地の画面へ（&in=dark で、土地の画面も同じ黒から明ける）。全体で約4.6秒（&flyms= で試験用にのばせる）
  - 印は虫ピン（鋼の細い針と先、付け根の座金、透明な上塗りのある丸い頭。少し傾けて刺す。刺した所の暗がりと、昼の側では太陽の反対へのびる頭の影）。東京は青、住んだ土地は赤、図鑑は黄（読んだら緑）。まだ行っていない土地の印は出さない。旅で着いたとき、上からピンが刺さる。印は町の単位（細かい位置は出さない）
  - 旅のメールは本物のメールのように、右上に通知がすべりこむ。押すと通知の場所から画面の真ん中へ広がって読める（［あとで］で通知に戻る）
- 画面の骨組み（段階2）：地図⇄近くは同じ立体の遠景と近景。地図で押した所へ飛んで寄り、［地図］で戻る（引きすぎると地図になる）。［季節を過ごす］は地図にだけ
  - 下の道具：家・畑・木・水・小屋・地形・消す。種類のある道具は、選ぶと上に種類が出る（木：果樹・生け垣、水：タンク・池・浄化設備、小屋：堆肥小屋・ニワトリ小屋、地形：上げる・下げる・平らに）
  - 1年の流れの変わり方：写しで1年＝4季節を過ごして、編集前の1年とくらべる（建てる時に一度だけ払うお金は数えない）。例：畑4×2m → とれる食べもの +9.8kg・買う食べもの −9.8kg・流れ去る水 +1.9m³

  - 木：押すと1本植える、なぞると並べる（果樹は2mおき、生け垣は1mおき）。果樹には実がなる。ある木を押すとカード（切って薪にする）
  - 小屋：堆肥小屋はなぞって区画を並べる（すかし板の囲い・片流れの屋根・中に堆肥の山）。ニワトリ小屋は押して置く（そばに数羽）

  - 地形：なぞった所を1段上げる・下げる・平らに。下書きのあいだは、変えた後の地形で描く
  - 学んでいないものは選べない（種類の頭に鍵）。季節の中でメールで教わる、天気の記録から先読みする
- 季節（段階4）：地図の［〇〜〇月を過ごす］で3か月を進める（engine.advance）。進める前に、その3か月の天気（計算に使った毎日の雨・日差し・気温）を早回しで見せる：1日≒70ms、雨の日は雨が降り（凍える日は雪）、曇ると日差しが弱まり画面が少し暗くなる。上に日付・天気・雨の合計と、日ごとの雨の棒。押すか［とばす］で飛ばせる。見せ終わってから結果に入れ替えて報告（?fast で飛ばす）。報告は、雨・所持金・流れの帯・土の有機物と収穫・届いたメール（学んだことは添付のノート）・出来事（選ぶものは選ぶ）。季節を過ごすと取り消しの履歴は消える。章の目標に届くと、招いてくれた人のメール

- 母屋のカード：太陽光（枚）・蓄電池（台）・基礎の深さ（学んでいれば）。地形に石垣、水にポンプ

- 編集の値段（11/27）：仮のあいだは何度変えてもただ。［✓ 決める］で、編集前と最後の差だけ払う（world.js の editCost。A→B→A は0円、A→B→C は C の分だけ）

  - タンク・ポンプ・太陽光パネル・蓄電池・ニワトリ小屋・沈殿槽は使い回す（数が増えた分だけ払う。屋根の太陽光を地面へ移すのもただ）
  - 仮のうちはお金が足りなくても試せる。足りないあいだは帯の金額が赤く、［✓］が押せない
- 時刻：0〜24時。日が沈むとブルーアワー、夜は月の光（太陽の反対側の高い所から青く）と窓の明かり。つまみの下に夜・朝焼け・昼・夕焼け・夜の帯
- 浄化設備：微生物の働きは水の色で見せる（家に近い入口は濁った茶、奥へ流れるほど澄んだ青。小さな泡は入口ほど多い）
- 新しい操作の試作（?proto、または ?play&ui=2）：寄ると下から丸が5つせり上がる（家・部屋・芽・地形・設備。dock.js）
  - 丸を押すと画面の下半分に窓（上に3Dを残す）。家：工法・屋根・基礎・建てる／部屋：壁を下げて、トイレ・シャワー・かまど／芽：畑・果樹・生け垣・ニワトリ・堆肥小屋／地形：上げる・下げる・平らに・石垣／設備：太陽光（［屋根に］［地面に］）・蓄電池・タンク・ポンプ・池・浄化設備
  - 物を押すと、その物の丸が光って窓が開く。何もない所を押すと閉じる。道具を選ぶと窓はたたみ、丸の上に今の道具（×でやめる）
  - 仮の物は設計図のように（素材の色を淡く透かし、青い線で縁どる）。壊す・外す物は青い点線、地形を変えたマスは青い枠
  - 取り消し・やり直しは編集の帯の中。消すのは各窓の［外す］［壊す］
  - 地面の太陽光：赤道の側へ傾けた架台に1枚ずつ（engine では傾き0.4として数える）
  - 家：地面をなぞると床が描ける（なぞっている間に、建てられるマス・切る木・値段が出る）。指を離すと白い模型の下書きになり、［建てる］を押すまで建たない（写しの世界で試しに建てて、値段と建てられない理由を出す）。下書きの壁も押せる。建物にくっつけて描くと広がり、離れて描くと新しい建物（離れ）。扉は母屋に向いた辺に、窓は間をあけて自動で
  - 壁を押すと、その壁のそばに［壁｜窓｜二重窓｜扉］の選択肢（値段と効き目。押した壁は黄色く光る）。1回押せば決まり、取り消せる。開いたまま、ほかの壁を押せば続けて変えられる。道具を持っていなくても、家の道具でも、下書きでも、壁を下げていても同じ。屋根や床を押すと建物のカード
  - 扉にする所に家具があれば、家具のほうを近くの置ける所へよける（world.settleFurn：もとの場所に近く、向きはそのまま、壁ぎわを少し好む）。よけられないときだけ選べず、理由を出す
  - 壁を下げる（上のボタン、または建物のカードの［中を見る・家具を動かす］）：壁を腰の高さで切り、屋根を外して、寝台・食卓・トイレ・シャワー・かまどを見せる。家具は壁の厚みのぶん内側に寄せて描く（めり込まない）。シャワーのガラスは壁のない辺だけ、食卓の椅子は両端
  - 家具：壁を下げているときに押すと選ばれ（縁が黄色）、そばに［回す］と種類（水洗⇄コンポスト、ふつう⇄節水）。家具の上で押したまま引きずると1m単位で動き、置ける所は緑・置けない所は赤の箱で出る。空いた床を引きずったときは今まで通り視点が回る（The Sims・あつまれ どうぶつの森と同じ分け方）
  - 家の中の壁（間仕切り）：壁を下げているときに、床の上をマス目の線に沿ってなぞると黄色い線が出て、離すと間仕切りが立つ（なぞった線が全部もう間仕切りなら赤で、外す）。部屋を閉じると、引いた線のまん中寄りに中の扉が自動でつく。間仕切りを押すと［間仕切り｜扉｜外す］。間仕切りは1mあたり1.2万円、中の扉は2万円、外すのは1mあたり0.2万円（どれも近所の大工さん）
    - 部屋＝間仕切り（壁も扉も）で分かれたマスのまとまり。扉でたどって外への扉まで行けない部屋があると建てられない。ベッドなど2マスの家具は間仕切りをまたげず、中の扉の両側のマスはあけておく（家具はよける）
    - 建物のカードに、部屋が2つ以上あれば部屋ごとの広さとベッドの数（▭）。暑さ寒さの計算には部屋を入れない
    - 泊める（考え中）：トミーは空いたベッドがあれば泊まれる。旅人は部屋が要る。人数が多いときは別棟
  - 水：地面を押すとタンク。軒の下（軒を押してもよい）なら雨どいが自動でつき、たてどいがタンクへ下りる。屋根から年に何m³集まるかを出す
  - 雨どいとタンクの見え方は計算の側の決まりと同じ：雨が落ちる軒の家のマスから1マス以内・入口が軒より低いタンクには、いちばん近い軒の樋からそれぞれたてどいが下りる（樋から1m近く離れたタンクは、角で地面まで下ろして地面の管で回す）。タンクのない軒は、角でたてどいを下ろし、家のまわりを地面にそっていちばん近いタンクの足もとへ。タンクが1つもなければ地面へ
  - タンクの外を向いた面に水の窓：雨が入るタンクは青、入らないタンクは空。雨が入るタンクどうしがとなり合うと、足もとを管でつなぐ。カードには入らない理由を場所から具体的に（妻側で雨が落ちない・軒より高い・となりより高い・軒から遠い）。屋根の雨がもう全部集まっているときに足したタンクは「ためられる量がふえる」と出す（前は「雨が入らない」と出ていた）
  - 消す：離れ・タンク・畑・木（木は切って薪に）。母屋は消せない
  - 編集：何か変えた時点で編集中になる（家・畑・木・水・小屋・地形・消す・建物のカード・壁・家具、全部同じ）。変えた物はすぐ本物の見た目で出るが、［✓ 決める］までは確定しない。下の帯は［✕］値段・1年の流れ［✓ 決める］だけ。所持金は「今 → 決めたら」、画面のふちに色、季節は過ごせない。✕で編集前に戻る。取り消し・やり直しは編集の中で効き、始めまで戻すと編集は終わる。決めた編集は取り消し1回ぶん。保存は決めたときだけ
  - 押した物の横に小さなカード（スマホでは下から）。建物は使い道（泊める・しまう・育てる）、工法（板とトタン／この土地の工法／断熱した。今の工法に印）、屋根の形（平ら・片流れ・切妻。瓦は傾けた屋根だけ、土の屋根は平らだけ）と下がる向き（片流れは北東南西、切妻は北と南／東と西）、屋根の傾きと軒の出、母屋は水まわりとかまど。屋根で受ける雨とタンクへの流れ。ピントは押した物に合う
  - 太陽光の発電は、パネルが載っている面の向きと傾きで月ごとに変わる（world.pvFactor：その土地の緯度で各月15日の太陽の動きから直達の比、散乱は空の見える割合。直達65%・散乱35%）。並べ方は world.pvLayout を計算と絵で共有。カードに「平らに置くのと比べて ×1.18」と面ごとの枚数。例：タオス南向き27°は ×1.18、北向き27°は ×0.67、メデジンでは南向きでも ×0.95（赤道に近いので平らがいちばん）
  - 続けて置いた物はつながって見える：となり合う窓はひと続きの横長の窓（枠を端までのばし、つなぎ目は細い桟）、扉がならべば両開き、生け垣はあいだを茂みでつないだ一本の垣根
  - 蓄電池（1台5kWh）は家の中の床に置く箱：カードの［＋ 置く］で壁を下げて床を押す。壁ぎわに部屋のほうを向いて立つ（緑の灯りと通気の筋）。押すとカード（外す）。前の作りの台数は、開いたときに壁ぎわの箱に置きかえる
  - 太陽光パネル（1枚0.2kW・約1m²）は屋根に描く：赤道を向いた面から並べ、入りきらなければ次の面へ。縦置き・横置きのうち多く乗る方。平らな屋根は赤道へ傾けた架台に、列をあけて。屋根に乗りきらない分は赤道側の地面に架台で（置いた物のあるマスは避ける）

- 始まり（段階4）：/ を開くと地球と題名。［はじめから］でトミーのメール → ［メデジンに行く］で東京から飛ぶ（上の寄り方）→ 着いた土地の気候（気温の帯と雨、東京とくらべる）→ 暮らし（engine の最初の家から）。［つづきから］は保存から。［地球儀で学ぶ］は世界の知恵の印を押して読み、［ノートに書く］で技術を学ぶ（保存があれば）。縦長の画面では地球を少し上に寄せる
- 次の土地：招待の［〜へ行く］で、お金（土地代を引く）・人・学んだこと・年・これまでの土地・届いた招待を持ち越して /?travel=<土地> へ。招待はもう読んであるので、地球儀は出発地を見せてすぐ飛ぶ（上の寄り方）
- 土地：メデジン（med）、ウブド（ubud）、アレンテージョ（alen）、八ヶ岳の麓（yama）、タオス（taos）。気候と地形は実データ、取れなかったときの仮の値は engine の SITES。ウブドと八ヶ岳の麓の工法はまだなく、「板とトタン／断熱した」だけ（建物のカードに［この土地の工法］が出ない）
  - アレンテージョの工法：白い土壁（タイパ。突き固めた土を石灰で白く、毎年塗り直す手入れ代。腰と窓まわりは藍か黄土の帯、白い線はなし）、素焼きの瓦（テリャ。テハと同じ見た目）、素焼きタイルの床（ティジョレイラ）。ゆるい切妻・浅い軒
